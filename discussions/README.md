# BugWitness Reviews & Discussions

This directory collects reviews, feedback, and debate from collaborators and AI
models across multiple rounds. Each entry represents one reviewer's perspective
at one point in time.

## Naming convention

`YYYY-MM-DD-{reviewer}-review-{round}.md`

Examples:
- `2026-04-30-deepseek-review-1.md`
- `2026-05-01-claude-review-1.md`
- `2026-05-10-deepseek-review-2.md`
